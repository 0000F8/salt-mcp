# Changelog

## 0.4.1 — 2026-11-17

- **`show_screen`** is annotated and listed: "Post a live screen card for the computer you're using into the chat, so the person can watch it and take control." It is an SDK action (`salt-agent-sdk` 0.38.0), exposed like the other SDK actions (not read-only, not destructive, not idempotent, open world). Needs `salt-agent-sdk` >= 0.38.0 installed to appear; the annotation test allows it ahead of the SDK.
